# Web-приложение для поиска ключевого слова в файлах

## Требования

* Python 3.11

## Установка и запуск 

```console
$ pip install -r /path/to/requirements.txt
$ fastapi run main.py
```

## Настройка

Все настройки лежат в файле `config.py`.

## Документация

Информация по работе с API доступна в /docs (пример: http://127.0.0.1:8000/docs)

## Описание реализации

Основная реализация сделана через поиск по индексам (параметр )
